# 开发记忆目录

`memory/` 用于在不同设备、不同开发会话之间同步项目上下文。它随 Git 提交，但不属于 PfinderWithAI 运行时数据，也不是 `CaseMemoryProvider` 的实现。

## 使用方式

1. 开始工作前阅读 `PROJECT_MEMORY.md`、`docs/Requirements.md` 和 `AGENTS.md`。
2. 只有在架构决策、实现状态、验证命令或已知风险发生变化时更新项目记忆。
3. 内容应简短、可验证，并链接到稳定文档或代码路径。
4. 过期信息应直接修正，不要无限追加相互矛盾的会话流水账。

## 禁止保存

- 访问令牌、Cookie、连接串、私钥或账号信息。
- 真实生产日志、客户数据、订单敏感值或内部地址。
- 完整模型 Prompt、完整代码副本或本地机器专属路径。
- 未经验证却被表述为事实的根因判断。

运行时调查数据默认写入被 Git 忽略的 `.pfinder/`，不要复制到本目录。
